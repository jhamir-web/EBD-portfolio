# E DESIGN & BUILD — Portfolio Website

Official modern architecture and construction company portfolio website for **E DESIGN & BUILD**.

Crafted with React, Tailwind CSS, and Vite, featuring an editorial architectural layout, Apple-inspired whitespace, authentic project monographs, technical floor plans, and interactive design-build showcases.

---

## 🏛️ Brand & Identity

- **Deep Navy**: `#0B1B33` (Visual anchor)
- **Dark Navy**: `#101F36`
- **Off White**: `#F7F7F5`
- **Light Gray**: `#E9EBEF`
- **Architectural Orange**: `#E8752A` (Restrained accent)

---

## 📐 Features

- **Architectural Monograph Layout**: Asymmetric editorial layout with thin technical lines, coordinate tags, and precision metadata.
- **Dual View Hero**: Toggle between 3D architectural perspectives and technical floor plan blueprints.
- **Selected Projects Archive**: 6 genuine documented projects with verified scopes, locations, duration schedules, and costs:
  - `01` Proposed Renovation of Existing Bungalow House (Malolos, Bulacan)
  - `02` Proposed Fence, Gate and Kitchen Extension (Malolos, Bulacan)
  - `03` Proposed Fence, Gate and Garage Roof (Malolos, Bulacan)
  - `04` Design for 2 Storey Residential with Roof Deck and Commercial Space (Zamboanga City)
  - `05` Design for 3 Bedroom Bungalow House (Cauayan City, Isabela)
  - `06` Design for Fence, Gate and House Extension (Plaridel, Bulacan)
- **Monograph Presentation Modal**: Full-screen project view with multi-image gallery and zoomable architectural drawings.
- **Capabilities & Services**: Typographic numbered grid with deliverables.
- **4-Stage Delivery Process**: Consult → Design → Plan → Build.
- **Interactive Project Inquiry**: Direct inquiry routing from project modals to contact form.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production
```bash
npm run build
```
